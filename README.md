# CAP Compétitivité — Gestion des affaires

Application web autonome (HTML/CSS/JS, sans backend) pour archiver les affaires commerciales une par une selon la méthode de l'échiquier : Identité affaire, Fiche RDV, Score 40, Qualification, Fiche Mission, Pilotage agence.

Les données sont stockées localement dans le navigateur de chaque personne (`localStorage`) — utilisez « Exporter tout » / « Importer » pour faire circuler des affaires entre plusieurs personnes.

## Utilisation

Ouvrez `index.html` dans un navigateur, ou activez GitHub Pages sur ce dépôt (Settings → Pages → branche `main` → dossier `/`).
